Why we're Glass Clear

The AI model behind Glagon runs on the developer's own computer, not in a big company's AI cloud.

The code for this website and for the server that talks to the model is public, so you can check how it works yourself.

View the source on GitHub →

Your privacy, stated plainly

Here is what happens to your messages:

  • Your browser encrypts each message before sending it. The website host (Cloudflare) and the tunnel (ngrok) pass along only encrypted data.
  • The server on the developer's computer decrypts your message so the AI can read it. This means the developer's computer can see your messages, and the encryption does not protect you from the developer.
  • The published server code does not save messages. It only prints error messages. You can verify this in the source.
  • Glagon does not remember earlier messages. Each message is answered on its own.

Please don't send passwords, personal data, or anything else sensitive.

Heads up: we're not always online. Glagon runs on a personal computer, so it may be offline sometimes. If it is, please try again later.
